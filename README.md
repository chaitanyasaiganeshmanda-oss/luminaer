# LUMINAER
A responsive website for LUMINAER, a student innovation concept for a portable personal-hygiene kit.

## Files
- `index.html` — website structure and content
- `style.css` — responsive styling
- `script.js` — navigation, discover dialog, daily checklist and feedback email

## Run locally
Open `index.html` in a modern browser. No build tools or package installation are required.

## Deploy with Vercel
Import this repository in Vercel. Use the Other framework preset, leave the build command empty, and set the output directory to `.` if prompted.

## Notes
The daily checklist uses browser localStorage. The feedback form opens the visitor's email application; it does not send mail through a backend. The optional UV-C sanitizing module is conceptual only. No sanitization performance or safety certification is claimed; UV-C needs full enclosure, effective interlocks and independent testing before real-world use.
